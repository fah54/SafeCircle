# 🛡️ SafeCircle – Your Safety, Your Power

**SafeCircle** is a women’s safety and digital awareness web application developed by **Team Cyberx** for a hackathon project.

Our goal is to make safety information and digital awareness guidance easier to access through a simple, user-friendly website.

## ✨ Features

### 1. Suspicious Message Checker
Checks submitted messages for common suspicious keywords and warning signs and provides basic guidance. It cannot guarantee that a message is safe or dangerous.

### 2. Safety Center
Provides a central place to navigate the available safety information and support pages.

### 3. Profile Safety
Shares guidance on protecting personal information and improving online profile privacy.

### 4. Harassment Support
Provides general guidance for responding to harassment and finding appropriate support.

### 5. Emergency Help
Displays emergency-related guidance and useful contact information. The prototype does not automatically contact emergency services or send SMS messages.

## 🚀 How to Run the Project

1. Open the project repository on GitHub.
2. Download the project files or clone the repository.
3. Keep the HTML, CSS, and JavaScript files in the required project structure.
4. Open `index.html` in a modern web browser.

The deployed website can also be accessed here:

**Live Website:** https://fah54.github.io/SafeCircle/

## ⚙️ Project Limitations

- The message checker uses basic keyword-based logic.
- It may produce incorrect results or miss suspicious messages.
- It does not provide guaranteed threat detection.
- It does not automatically share the user's location, send SMS messages, or contact the police.
- Users should contact appropriate emergency services directly when immediate help is needed.
